# TransWrite · El Dorado

Propuesta pedagógica digital asociada al proyecto de investigación **Uso del Translenguaje para la producción textual en Inglés con los estudiantes de Media Académica en la IE El Dorado de Montería**.

## Propósito

El sitio traduce la base conceptual del proyecto en una ruta funcional de producción escrita en inglés. La versión inicial organiza siete momentos:

1. My Idea
2. Meaning Bridge
3. Plan My Text
4. Write in English
5. Check the Meaning
6. Rewrite
7. My Reflection

La arquitectura es provisional y deberá ajustarse con las categorías y relaciones emergentes del Capítulo IV.

## Tecnología

- HTML
- CSS
- JavaScript
- LocalStorage del navegador
- GitHub Pages

No requiere servidor ni base de datos para esta primera versión.

## Publicación

El sitio está preparado para publicarse desde la rama `main` mediante GitHub Pages.
